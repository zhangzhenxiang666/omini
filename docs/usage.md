# 使用指南

## 启动项目

安装 Omini 后，在要处理的项目目录运行：

```bash
omini
```

首次使用时完成模型服务配置。若已有配置，Omini 会读取用户级配置，并应用当前项目的覆盖项；详见[配置参考](configuration.md)。

直接输入任务，例如“检查登录流程的错误处理”或“为这个模块补充边界测试”。Agent 可以阅读文件、修改代码并运行命令；需要确认的操作按照[权限规则](permissions.md)处理。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `/help` | 查看可用命令和技能 |
| `/init [要求]` | 分析项目并生成或更新 `AGENTS.md` |
| `/sessions` | 继续或切换已有会话，别名为 `/resume` |
| `/new` | 开始新会话，别名为 `/clear` |
| `/rename <名称>` | 重命名当前会话 |
| `/plan` | 切换到计划模式，先讨论方案再执行 |
| `/model` | 切换模型 |
| `/effort <强度>` | 调整支持推理的模型的思考强度 |
| `/compact [要求]` | 压缩当前会话上下文 |
| `/agents` | 管理可用的 Agent |
| `/<skill-name> [要求]` | 调用可用的 Skill |
| `/exit` | 退出，别名为 `/quit` |

`/effort` 支持 `none`、`low`、`medium`、`high`、`xhigh` 和 `max`。实际可用能力取决于当前模型配置。

## 后台任务与子 Agent

Agent 可将独立工作交给后台 Agent，耗时 Bash 命令也可在后台运行。任务完成后会自动通知主 Agent，无需手动轮询；主 Agent 可以继续处理结果。等待期间仍可提交新消息。

选择仍运行的直接子 Agent 会话后，可以向它补充要求；已结束的子任务不能再接收新输入。

后台 Bash 沿用原有权限和执行超时，不会因为转入后台重新计时。默认总超时为 120 秒，最长可设为 600 秒。

## 停止运行

在主会话输入时按 Esc：

- 没有后台任务时，直接停止当前运行。
- 存在后台任务时，先确认是否停止当前运行及全部后台任务，包括子任务。默认保留工作；确认停止后才发出取消请求。

在子 Agent 会话中按 Esc，只停止该子任务及其后代。

主动停止后，任务结果仍可查看，但完成通知不会自动启动主 Agent。再次提交消息时，Agent 会取得相关结果。

Unix 上取消或超时会终止 Bash 命令及其进程组中的子进程；自行脱离进程组的程序不在此范围内。

## 管理本地服务

Omini 会在需要时启动本地服务。可用以下命令检查或管理它：

```bash
omini server status
omini server start
omini server stop
omini server restart
```
